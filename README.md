# 🌾 Farm Management System (Projeto Acadêmico)

Este projeto é um sistema de gerenciamento agrícola desenvolvido em Java. Ele auxilia no controle de atividades agrícolas, gerenciamento de culturas e monitoramento de recursos.

## 🚀 Tecnologias Utilizadas

- **Linguagem:** Java
- **Framework:** Spring Boot
- **Banco de Dados:** MySQL
- **Outros:** Docker

## 📦 Funcionalidades

- Cadastro e gerenciamento de culturas agrícolas.
- Monitoramento de recursos e insumos.
- Relatórios de produtividade e eficiência.
- Interface amigável para usuários administrativos.
